# Острова Лабеан — пилотная веб-версия

Пошаговая стратегия на пятерых: два архипелага, 36 районов, семь фракций, стартовый выбор районов, пять раундов, скрытые армии и одновременный подсчёт боёв.

## Запуск

Нужен Node.js 20 или новее. Внешних зависимостей нет — `npm install` не требуется.

```bash
npm start            # сервер на http://localhost:8080 (порт меняется через PORT=...)
npm test             # автотесты движка, ботов и сервера движка и сервера
```

Партии сохраняются в `data/rooms/*.json` (путь меняется через `DATA_DIR`). После перезапуска сервера партии продолжаются с того же места.

### Как сыграть

- **По сети.** Создатель комнаты получает четырёхбуквенный код, остальные входят по коду и имени. Партию начинает создатель, когда собрались пятеро.
- **Проверить в одиночку.** В лобби кнопка «Заполнить тестовыми игроками» выдаёт четыре ссылки — откройте каждую в отдельной вкладке (или окне инкогнито) и ходите за всех.
- **Против компьютера.** На главной странице оставьте галочки «компьютер» — четыре места займут боты. В сетевой комнате создатель может нажать «Добавить компьютеров»; если потом войдёт друг, он займёт место бота.
- **За одним экраном.** На главной странице — партия для пятерых за одним устройством, движок работает прямо в браузере, между ходами экран закрывается шторкой. Отдельная страница этого режима — `/play.html`.

## Архитектура

```
shared/config/   данные: карта, фракции, юниты, карты, параметры правил
shared/engine/   игровой движок — чистые функции, без интерфейса
  game.js        фазы, проверка действий, подсчёт раунда, награды, раздача
  effects.js     обработчики всех 23 карт и проверка их целей
  battle.js      разрешение боя за один район
  board.js       граф соседства (стороны + мосты)
  views.js       представление партии для конкретного игрока (скрытая информация)
  rng.js         детерминированный ГСЧ, состояние хранится в партии
  bot.js         компьютерный игрок
server/          HTTP + SSE без зависимостей, комнаты, таймеры, атомарное сохранение
client/          интерфейс на нативных ES-модулях
  assets/map.png игровая карта (подложка)
  js/ui/mapgeom.js  контуры районов, мостов и тексты из MAP_FRAME.svg (сгенерировано)
tests/           node:test
docs/            открытые вопросы, визуальная система, отчёт
```

Ключевые решения:

- **Сервер — доверенная сторона.** Игрок определяется по секретному токену, а не по полю запроса. Клиент получает только своё представление: чужие юниты, карты и тайные бонусы физически не попадают в браузер соперника.
- **Команды атомарны и идемпотентны.** `applyCommand` работает на копии состояния: ошибка не оставляет частичных изменений. У каждой команды есть id — повторная отправка (двойной клик, обрыв связи) не выполняется второй раз.
- **Сохранение** — запись во временный файл и переименование, так что сбой посреди записи не портит партию.
- **Карты описаны данными** (`config/cards.js`) и обработчиками (`engine/effects.js`). Новая карта — это запись в конфиге и функция, интерфейс подстраивается по типу цели.
- **Порядок разрешения эффектов** зафиксирован в `RESOLUTION_ORDER` (`game.js`).
