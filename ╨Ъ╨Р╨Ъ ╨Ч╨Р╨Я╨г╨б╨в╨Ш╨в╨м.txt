ОСТРОВА ЛАБЕАН — КАК ЗАПУСТИТЬ

1. Играть одному против компьютера или с друзьями за одним экраном
   Откройте файл play.html двойным щелчком. Ничего устанавливать не нужно.
   Папку client рядом с ним не удаляйте и не переносите — там карта и карточки.

2. Играть по сети (у каждого свой компьютер или телефон)
   Нужен Node.js 20 или новее (https://nodejs.org, кнопка LTS).
   Windows: двойной щелчок по «Запустить сервер (Windows).bat».
   Mac: двойной щелчок по «Запустить сервер (Mac).command»
        (если Mac не даёт открыть — правый щелчок → «Открыть»).
   Откроется http://localhost:8080 — создайте комнату.
   Чтобы друзья подключились из интернета, игру нужно выложить на хостинг:
   инструкция в docs/DEPLOY.md.

Если вы меняли код игры — пересоберите play.html командой: npm run build
