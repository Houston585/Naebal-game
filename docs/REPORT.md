# Отчёт о готовности пилота

Дата: 27.10.2026. Версия 0.1.0.

## Итог

Партию на пятерых можно провести от подготовки первого раунда до итогового подсчёта очков — по сети (сервер) или за одним экраном. Проверено автотестами (100) и прогоном в браузере: создание комнаты, выбор фракций, подготовка, розыгрыш карты с выбором цели, выставление юнита с подсветкой допустимых районов, фазы «Авторитета» с перетаскиванием, сводки раундов и финальный экран.

## Критерии приёмки (ТЗ 16.7)

| Критерий | Статус |
|---|---|
| Партия на пять игроков | Готово: сеть и один экран |
| Пять раундов в правильном порядке | Готово, тест `rounds.test.js` |
| Действия и бои по ТЗ | Готово, все примеры 3.3 покрыты тестами |
| Юниты и карты | Все 12 типов юнитов и 23 карты работают; неутверждённые места — временные решения из `OPEN_QUESTIONS.md` |
| Изменение карты при захвате и уничтожении | Готово, с анимацией |
| Скрытая информация | Защищена на сервере; тесты `integrity.test.js`, `server.test.js` |
| Сохранение и восстановление | Готово: перезагрузка страницы, переподключение, перезапуск сервера |
| Автотесты критических сценариев | 100 тестов |
| Ограничения документированы | Этот файл и `OPEN_QUESTIONS.md` |

## Покрытие тестами

- **Бои:** шесть обязательных примеров ТЗ, сложение сил одного игрока, раздельность сил разных, равенство атаки и защиты, укреплённые и неигровые районы.
- **Карта:** 36 уникальных районов, столицы, нейтральные территории, соседство только по сторонам, мосты, уничтожение района и моста, связность всех территорий.
- **Раунды:** стартовая армия, один ход на игрока, отмена невозможна, чужой/использованный юнит, пул и перераздача без потерь и дубликатов, доп. юнит перед 4-м раундом, лимит пула, таймауты, порядок ходов.
- **Карты:** каждая из 23 карт — момент розыгрыша, проверка цели, эффект; награды территорий (первый захват, без повторов, раздел территории).
- **Информация:** чужие юниты, карты, тайный бонус, БПЛА, выпавшая награда.
- **Устойчивость:** идемпотентность, атомарность при ошибке, восстановление из JSON, детерминированный ГСЧ, шесть полных случайных партий с картами, рестарт сервера, отключение игрока, подмена игрока в запросе.

## Карта v2 (28.10.2026)

- Подложка — PNG из ТЗ, поверх — 36 зон и 3 моста из MAP_FRAME.svg с исходной прозрачностью и текстовый слой. Меняется только цвет заливки: белый, цвет фракции или чёрный.
- Карта занимает основную часть экрана и всегда видна целиком: рамка масштабируется по ширине или высоте доступной области (проверено на 1280×720, 1440×900, 1920×1080).
- Стартовая фаза: укрепрайоны закрепляются автоматически, затем 3 круга выбора районов.
- Проверки раздела 15 ТЗ покрыты тестами `map.test.js` и `draft.test.js`.

## Известные ограничения

- Режим «за одним экраном» защищает скрытую информацию только шторкой: всё состояние находится в браузере. Для честной игры — сетевой режим.
- Тестовые игроки, у которых не открыта вкладка, считаются отключёнными: через паузу на переподключение их ходы пропускаются.
- Нет аккаунтов: игрок привязан к комнате токеном в браузере. Открыть ту же роль на другом устройстве можно ссылкой с токеном.
- Нет экрана просмотра архива завершённых партий (журнал хранится в файле комнаты).
- Шрифты Unbounded и Golos Text загружаются с Google Fonts; без интернета будет системный шрифт.
- Интерфейс рассчитан на ноутбуки и мониторы; на телефоне работает, но карта мелкая.
